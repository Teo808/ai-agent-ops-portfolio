Candidate profile

I am strongest when the agent leaves the demo and hits real life.

I'm Matteo Stincone, a hands-on builder and tester. I work best where an AI workflow has to use tools, keep the right context, survive setup, and still make sense to a real person using it.

Target roles

AI support, workflow operations, and forward deployed engineering

My strongest lane is the practical layer around AI systems: setup, tools, APIs, memory, browser workflows, troubleshooting, documentation, and support. I am also interested in technical support and implementation roles where the work is hands-on and evidence matters.

Why call me back

I pay attention to the layer where agents either become useful or fall apart.

I notice the things that quietly ruin trust: unclear setup steps, memory pulling the wrong context, tools that look connected but silently fail, browser workflows that break on real input, and provider behavior that changes without a clear explanation. Then I document the path clearly enough for someone else to reproduce and fix it.

How I operate

Setup feels fragileI reproduce the failure and write a reliable path, not just fix it once for myself.
Memory gets noisyI check whether the agent is using the right project, source, and current state.
Tools fail weirdlyI check authentication, transport, names, server state, and the smallest safe call.
A report is vagueI turn it into symptoms, environment, expected behavior, actual behavior, and verification steps.
